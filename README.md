# Automated Irrigation
A university project where I built an automated irrigation system using a Texas Instruments MSP430.

# What I Learned
- Implementing a UART protocol
- Using an Analog-To-Digital Converter
- Using non-volatile storage
- Configuring hardware timer interrupts
- Debugging multidisplinary systems
- Designing GUIs in Windows Forms
- Scripting CSV files
- Peripheral circuit design
